# قائمة التشغيل النهائية — المنارة

## أول تشغيل عندك

1. فك ضغط المشروع وادخل إلى المجلد.
2. اضبط تكاملات الـ Sandbox:

```bash
cp config/integrations.example.sh config/integrations.local.sh
nano config/integrations.local.sh
source config/integrations.local.sh
```

3. تأكد من MySQL وقاعدة البيانات `ubs_training` أو عدّل DataSource بما يناسب بيئتك.
4. نفّذ:

```bash
grails compile
./gradlew test
grails run-app
```

أو استخدم:

```bash
./scripts/verify-project.sh
```

## أهم سيناريوهات الفحص

### Braintree Sandbox
- افتح عملية شراء أو حجز غرفة أو حجز كتاب `READY` لمستخدم **غير مشترك** (الحجز المشمول بعضوية فعالة لا يذهب إلى Braintree).
- استخدم Test Card فقط: `4111 1111 1111 1111`، تاريخ مستقبلي، CVV تجريبي.
- تأكد أن سجل Payment يحتوي transaction id وآخر 4 أرقام فقط.

### حجز الغرف
- جرّب يومًا عاديًا: يجب الانتقال للدفع، وبعد نجاحه فقط يظهر RoomReservation بحالة `CONFIRMED`.
- جرّب `15/11/2026`: يجب رفض الحجز قبل الدفع باعتباره ذكرى إعلان الاستقلال.
- جرّب وقتًا متداخلًا مع حجز مؤكد: يجب رفضه.
- جرّب مدة أطول وتأكد أن السعر يعرض قاعدة الخصم المطبقة.

### حجز/استعارة كتاب
- بدون عضوية فعّالة ومع نسخة متاحة: الحجز يصبح `READY` ويظهر `borrowingFee`.
- أكمل الدفع: يجب أن يصبح `PAID`، ولا تبدأ مدة الاستعارة بعد.
- مع عضوية فعّالة: الحجز يصبح `READY` برسوم `0`، ثم يتأكد مباشرة إلى `CONFIRMED` بدون فتح Braintree.
- عند التسليم من الإدارة في الحالتين: ينشأ `Borrowing` وتبدأ مدة 14 يومًا ويصبح الحجز `FULFILLED`.
- مع عدم توفر نسخة: يبقى `WAITING` إلى أن تعود نسخة متاحة.
- جرّب عضوية تبدأ مستقبلًا: يجب أن تكون `SCHEDULED` ولا تجعل الاستعارة مجانية قبل تاريخ البداية.
- جرّب تأخير كتاب: رسوم التأخير تبقى مستقلة حتى لو كان المستخدم عضوًا.

### الكاونتر
- جرّب استعارة مباشرة لمستخدم لديه عضوية فعالة: يجب أن تبدأ الاستعارة بدون إنشاء Payment للاستعارة.
- جرّب استعارة مباشرة لغير عضو: يجب تسجيل Payment ثم الاستعارة.
- جرّب بيع كتاب ورقي نقدًا أو بطاقة كاونتر.
- تأكد أن الحركات المدفوعة تظهر في سجل المدفوعات بقناة `COUNTER`.

### إضافة كتاب
- أدخل ISBN واضغط جلب البيانات.
- راجع البيانات المقترحة من Google Books/Open Library قبل الحفظ.
